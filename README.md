# Учим сербский

Небольшая браузерная игра для детей 8–10 лет: изучение сербских слов (кириллица) с русским интерфейсом.

## Возможности

- 7 тематических уровней (приветствия, числа, цвета, семья, животные, еда, школа)
- 3 мини-игры: карточки, викторина, пары
- Звёзды, опыт (XP), награды
- Сохранение прогресса в браузере (`localStorage`)
- Озвучка сербских слов нейро-голосом (кнопка «Послушать») — записи Microsoft TTS

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте в браузере адрес из терминала (для GitHub Pages base: `http://localhost:5173/serbian-kids-game/`).

Сборка:

```bash
npm run build
npm run preview
```

## GitHub Pages

1. Создайте репозиторий **`serbian-kids-game`** на GitHub (имя должно совпадать с `base` в `vite.config.js`).
2. Загрузите код в ветку `main`.
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. После успешного workflow игра будет доступна по адресу:

   **https://sergjey.github.io/serbian-kids-game/**

## Озвучка новых слов

После добавления слов в `levels.json` перегенерируйте аудио:

```bash
pip3 install edge-tts   # один раз
npm run generate-audio
```

## Как добавить слова

Отредактируйте [`src/data/levels.json`](src/data/levels.json):

```json
{
  "id": "my_topic",
  "title": "Название темы",
  "icon": "🎵",
  "words": [
    { "sr": "Реч", "ru": "Речь" }
  ]
}
```

Добавьте тему в массив. Порядок в файле задаёт порядок на карте и цепочку разблокировки.

## Для родителей

- Прогресс хранится только в этом браузере на этом устройстве.
- Сброс прогресса: меню «Для родителей».
- Звуки можно отключить там же.
